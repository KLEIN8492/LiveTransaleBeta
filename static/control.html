Transcript

Captions appear here once the session is live — the original in the speaker's language, translations beside it. Start the session from Setup.

Caption look
Edits apply instantly to every screen using this look. Use one look per output, e.g. “fr-lower-third”.
NDI outputs
1920×1080 with transparency, same look as the browser overlay. OBS: Sources → NDI Source → choose the name. vMix: Add Input → NDI → choose the name, on an overlay channel.
Browser overlay
vMix: Add Input → Web Browser, 1920×1080, on an overlay channel. OBS: Sources → Browser, 1920×1080. Force any setting in the address, e.g. &lang=es&size=60. For recorded video, download subtitle files from Live.
